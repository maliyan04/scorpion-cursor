# 🦂 Scorpion Cursor

An animated scorpion built with pure HTML5 canvas — it tracks your mouse (or finger on touch devices) and follows you across the screen with a segmented body, jointed legs, pincers, and a curling stinger tail.

**Live demo:** https://maliyan04.github.io/scorpion-cursor/

## Features

- Segmented spine that trails behind the cursor using a chain/IK-style follow algorithm
- 8 animated legs with a simple stepping gait
- Pincers near the head and a curling, wobbling stinger tail
- Fully responsive — works with touch/drag on mobile, no external libraries
- "About the Developer" info card built into the page

## Tech

- Vanilla HTML, CSS, and JavaScript
- Canvas 2D API for all rendering
- No frameworks, no build step — just open `index.html`

## Run it locally

```bash
git clone https://github.com/maliyan04/scorpion-cursor.git
cd scorpion-cursor
```

Then just open `index.html` in your browser, or use VS Code's Live Server extension.
